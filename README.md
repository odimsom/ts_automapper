# ts_automapper

Librería en TypeScript inspirada en AutoMapper de C# para facilitar el mapeo entre objetos.

## Estado del proyecto

Proyecto en desarrollo inicial.

## Requisitos

- Node.js 18+
- npm o pnpm

## Instalación

```bash
npm install
```

## Ejecución en desarrollo

```bash
npm run dev
```

## Scripts disponibles

- `npm run start`: inicia la app
- `npm run dev`: inicia en modo desarrollo con nodemon
- `npm run test`: script de prueba base del proyecto
